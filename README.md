# Lunifer WHOOP Integration Demo

This repository contains a standalone HTML demo showing how Lunifer integrates WHOOP data into its personalized sleep recommendations and adaptive alarm experience.

## Open the demo

### Option 1: Download the file from GitHub

1. Open [`demo.html`](./demo.html) on GitHub.
2. Click **Download raw file** in the top-right corner of the file view.
3. Open the downloaded `demo.html` file in Chrome, Safari, Firefox, or another modern web browser.

If the file opens in a text editor instead, right-click it, choose **Open With**, and select your browser.

### Option 2: Clone the repository

```bash
git clone https://github.com/douglasbrown11/WHOOP-demo.git
cd WHOOP-demo
```

Then open the file directly:

- macOS: `open demo.html`
- Windows: `start demo.html`
- Linux: `xdg-open demo.html`

You can also drag `demo.html` into an open browser window.

## Notes

- No build process or package installation is required.
- The demo is self-contained and runs locally in the browser.
- GitHub's source-code view does not render the page; download or clone the HTML file to view the interactive design.
